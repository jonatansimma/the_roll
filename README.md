# Project ROLL

A DIY prototype to add a visible LED signal to a scent-detection dog's existing retrieval indication.

A trained dog wears a cylinder around its neck. When it finds a target scent, it takes the cylinder (the **Roll**) into its mouth and returns to its handler. Project ROLL explores how to detect that retrieval and turn on LEDs without disrupting the dog's trained behavior.

## Goal

Build and test **one working, battery-powered prototype** that:
- Detects deliberate mouth retrieval.
- Activates clearly visible LEDs.
- Avoids unacceptable false signals during normal activity.
- Fits the electronics in a practical cylindrical enclosure.

This is an experimental DIY project, **not a commercial product**. Sensor choice, dimensions, electronics, and performance targets are still to be established through testing.

## Approach

**Build → test → troubleshoot → improve.** Start with simple, affordable components and bench experiments; integrate into a cylinder only after basic functionality works.

**Safety first:** test away from the dog initially. Do not begin supervised dog testing until mechanical and electrical safety checks have been completed, including battery containment, bite exposure, loose parts, heat, moisture, and attachment risks.
